# TokensLab

Offline-first desktop app for **spend × sessions × tokens**, plus a read on productivity.

Claude Code is priced live against Anthropic’s rate card. Cursor, Codex and Gemini sit on the tray until their logs can carry a dollar figure. Nothing leaves your machine.
